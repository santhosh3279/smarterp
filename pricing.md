# Pricing

One licence per company, renewed yearly. Every plan includes software updates and remote support for the licence period.

<PricingTable show-extras />

## What is included in every plan

- Installation on your server or our cloud
- Keyboard-first Sales Entry and Cashier Desk
- Role-based screen access per user
- Remote support during business hours
- All updates released during the licence period

## Choosing modules

Each screen in SSPL Billing is a licensable feature. If a plan is close but not exact, we can add or remove individual modules — see the full list on the [Features](./features) page.
