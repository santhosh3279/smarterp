# Frequently asked questions

## Do I need ERPNext?

Yes. SSPL Billing runs on Frappe / ERPNext v16. If you don't run ERPNext yet, we install and configure it as part of implementation.

## Can it run on my own server?

Yes. It runs on any Linux server that can run ERPNext. We can also host it for you.

## Does it work without internet?

The application runs on your local network. Item and customer search uses a browser cache, so lookups stay fast even on slow connections. Saving bills needs a connection to the server.

## How many counters can bill at the same time?

There is no limit from the software. Each counter is a browser tab; draft bills from all counters appear at the Cashier Desk.

## Can I restrict what each user sees?

Yes. An administrator chooses which dashboard tiles each user can open. Billers, cashiers and accounts staff each get their own set of screens.

## Which printers are supported?

Any printer that works with the browser, including thermal receipt printers and A4 laser printers. Each document type can be mapped to its own printer and print format.

## Can I upgrade my plan later?

Yes. Additional modules are unlocked by updating the licence — no reinstall, and your data stays as it is.

## How is pricing calculated?

See [Pricing](./pricing). The final quote depends on the number of users, stores and modules you need.
