# Keyboard shortcuts

SSPL Billing is designed to be used without a mouse. Press **Shift+F1** on any billing screen to see the shortcuts for that screen.

## Bill actions

| Key | Action |
|---|---|
| F2 | New bill |
| Ctrl+S or F8 | Save bill |
| F5 | Print bill |
| F1 | Open Command Line |
| Shift+F1 | Show the shortcuts panel |
| End | Jump to discount / save |
| Insert | Open incentive entry |
| Esc | Back / cancel |

## Moving around the bill

| Key | Action |
|---|---|
| Up / Down | Move between rows |
| Tab | Next column in the row |
| Shift+Tab | Previous column in the row |
| Home | Jump to the first row |
| Page Up | Focus the series selector |
| F3 | Focus the modify panel (sidebar) |

## Item rows

| Key | Action |
|---|---|
| Enter | Confirm item code and move to quantity |
| Delete | Delete the selected row |
| Backspace | Restore the last deleted row |
