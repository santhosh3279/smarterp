Printing ​

Print formats ​

Each billing series has a default print format, set in SSPL Billing Settings. Thermal (receipt) and A4 formats are supported.

Printer mapping ​

Administrators can map each document type to a specific printer and format — for example sales bills to the counter thermal printer and purchase orders to the office laser printer.

Printing a bill ​

  • Press F5 on the billing screen, or
  • Print from the Cashier Desk after submitting the bill.

Use the print options window to choose a different format or printer for a single print.
