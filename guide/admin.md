# Users, access & settings

These screens are for administrators.

## Creating a user

1. Open **Create User**.
2. Enter name, email and mobile number.
3. Set the default price list for the user where needed.
4. Save, then grant screens as below.

## Granting screens

Each dashboard tile is a permission. In **Dashboard Tile Access**, pick the user and tick the tiles they may open. A user without any tile access gets the default set for their role (biller, cashier or accounts).

A tile only appears if it is also included in your company's licence.

## SSPL Billing Settings

Defines the **billing series** your counters use. For each series you set:

- Print format
- Price list
- Tax rate

## Naming Settings

Controls which numbering series each user can use for each document type.

## General settings

App-wide preferences such as default warehouse, default series, and display options.
