# Getting started

SSPL Billing is a fast billing and back-office screen set that runs in your web browser on top of ERPNext. This guide walks through the daily flow for each role.

## What you need

- A modern browser — Chrome or Edge recommended
- The address of your SSPL Billing site, given by your administrator
- A user name and password

## Logging in

1. Open your SSPL Billing address in the browser.
2. Enter your user name (usually your email) and password.
3. Press **Enter**. You land on the **Dashboard**.

If you open a screen without logging in, you are sent back to the login page automatically.

::: tip First load takes a few seconds
On the first login of the day the Dashboard downloads items and customers into the browser so that search is instant afterwards. Wait for the sync to finish before you start billing.
:::

## Who does what

| Role | Main screens |
|---|---|
| **Biller** | Sales Invoice, Quotation, Sales Order, Customer Enquiry |
| **Cashier** | Cashier Desk, Cashier Management, Payment Receipt |
| **Purchase / store** | Purchase Invoice, Purchase Desk, Store Transfer, Repack, Stock Reconciliation |
| **Accounts** | Ledgers, Journal / Contra, Cheque Register, GST Ledger, Reports |
| **Administrator** | User access, Billing Settings, Naming Settings, HRMS |

Your administrator decides exactly which screens you see — see [Users, access & settings](./admin).
